Device view demo

Start the mock hub with npm run demo:device-view, build the bundle with npm run build:device-view, serve this folder tree over HTTP (for example python3 -m http.server in studio/frontend) and open /device-view-demo/index.html. Defaults match the mock hub: port 8765, token demo. Override with ?url=ws://127.0.0.1:PORT/device/v1&token=....

Click = tap, drag = swipe, hold 500 ms = long press, Alt+click = select, type with the screen focused.
